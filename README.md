## Photo Archive - Alexandr Kravvi

An archival portfolio of photographic works by Alexandr Kravvi, a professional fine art photographer and retoucher.

🔗 **Website link:** [https://kravvi.github.io/archive](https://kravvi.github.io/archive)

This archive presents a selection of photographic works created throughout the professional career of Alexandr Kravvi, covering portraiture, fashion, editorial, and other visual projects.

#### About the Project

This repository contains the source code and visual assets for the "Alexandr Kravvi Photo Archive" website.

The archive is organized into thematic collections, including:

- Women's photos
- Men's photos
- White photos
- Kids' photos
- Model tests
- Nature patterns
- Coffee
- Miscellaneous
 
The collection may be expanded with additional categories in the future.
